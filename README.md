# house-price-prediction
House Price Prediction using Machine Learning

A machine learning project that predicts house prices using Python, Pandas, and the Random Forest Regressor algorithm.

Features
Load housing data from a CSV file.
Train a Random Forest regression model using five house features.
Evaluate model performance using Mean Absolute Error (MAE) and R² score.
Save the trained model using Joblib.
Predict house prices based on user-provided property details.

Technologies Used
Python
Pandas
Scikit-learn
Joblib

Project Objective
The goal of this project is to build and evaluate a machine learning model that estimates house prices based on property characteristics, then uses the trained model to predict prices for new houses.
